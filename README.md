
# Machine Learning Based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence

## 📌 Project Overview

This project applies Machine Learning techniques to segment buyers based on demographic, financial, and transaction characteristics. The objective is to identify customer groups and generate actionable business insights for real estate organizations.

---

## 🎯 Objectives

- Customer Segmentation
- Investment Profiling
- Exploratory Data Analysis
- Machine Learning using K-Means Clustering
- Interactive Dashboard Development

---

## 📂 Dataset

The project uses two datasets:

- Clients Dataset
- Properties Dataset

After preprocessing and feature engineering, both datasets were merged for analysis.

---

## 🤖 Machine Learning

Algorithm Used:

- K-Means Clustering

Model Evaluation:

- Elbow Method
- Silhouette Score (0.302)

Number of Clusters:

- Cluster 0
- Cluster 1
- Cluster 2
